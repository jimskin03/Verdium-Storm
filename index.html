Autonomous AI Agent & Spectator Interface

Verdium Storm supports programmatic play and spectating via browser automation.

To enable the agent API: load with query parameter ?agent=1&pacing=deliberate. This exposes `window.VS_AGENT`.

Available VS_AGENT methods: observe(), command(requestId, action), events(afterEventId, limit), waitFor(options), start(), step(ticks), getSpectatorInfo().

Entity IDs are numeric. Observation includes units, buildings, economy, production queues & available items with costs/lock reasons, known resources, objectives, and map bounds.

Spectator Mode: Operators can view matches live by visiting ?spectate=ROOMCODE&pass=PASSCODE or using the Spectate tab in the Multiplayer menu with room code and passcode.
